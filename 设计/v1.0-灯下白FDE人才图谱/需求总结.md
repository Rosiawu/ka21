# 灯下白 FDE 人才图谱｜需求总结

## 1. 产品目标

把《灯下白》已经上线的 58 期访谈，转化为一套可检索、可展示、可被搜索引擎与 AI 理解的 FDE 人才与能力目录。

这个页面同时承担三种职责：

1. 对甲方：快速判断主理人手上有哪些可匹配的业务实践者，以及他们可能交付什么。
2. 对主理人：按行业、角色、能力、交付方式、客户类型统计与筛选嘉宾。
3. 对搜索与 AI：通过独立详情页、完整公开 Shownotes、结构化数据和机器可读目录形成长期可发现的内容资产。

## 2. 核心原则

- 定位为“人才图谱 + 行业解决方案”，不是单纯的播客列表。
- 嘉宾卡片封面与详情页均可进入完整资料，并保留小宇宙原始链接。
- 不公开价格；合作范围、档期与报价统一由吴熳沟通。
- 联系方式清晰但克制：`139 1134 9663`。
- 所有标签来自公开访谈整理，不承诺嘉宾对所有项目均有档期。
- 公开站点只使用公开 RSS 内容，不暴露小宇宙后台私有数据。

## 3. 用户与关键任务

| 用户 | 关键任务 | 成功信号 |
| --- | --- | --- |
| 企业决策者 | 按业务问题找到适合的人 | 3 分钟内进入目标嘉宾详情并发起联系 |
| 项目负责人 | 比较能力、行业与交付方式 | 能筛出候选短名单并理解每人的公开案例 |
| 主理人 | 统计嘉宾结构、对外展示资源池 | 58 期均有分类，标签口径统一 |
| 搜索引擎 / AI | 理解人物、能力、节目与联系方式 | 可抓取独立 URL、JSON-LD、llms.txt 和目录 JSON |

## 4. 信息架构

### 人才图谱主页 `/[locale]/fde`

- 价值主张与联系电话
- 58 期 / 60 位嘉宾 / 行业方向 / 能力方向数据概览
- 六类典型业务场景快捷入口
- 搜索与多维筛选：行业、能力、交付方式、排序
- 嘉宾卡片：封面、姓名、定位、标签、简介、详情页、小宇宙链接
- 底部联系与报价说明

### 嘉宾详情页 `/[locale]/fde/[slug]`

- 人物定位、行业、角色与能力标签
- 播客封面，点击进入小宇宙
- 嘉宾简介、发布日期、时长与在线播放
- 完整公开 Shownotes
- 可匹配交付方向、客户类型与合作提示
- 同方向嘉宾推荐

### 机器可读入口

- `/llms.txt`：面向 AI 检索的站点说明与人物索引
- `/fde-catalog.json`：完整人才目录及标签数据
- `/sitemap.xml`：中英文目录页和全部人物详情页
- 页面 JSON-LD：`CollectionPage`、`ProfilePage`、`Person`、`PodcastEpisode`、`ProfessionalService`

## 5. 数据口径

- 节目内容：小宇宙公开 RSS，同步 58 期封面、标题、时长、链接、简介和完整 Shownotes。
- 人才分类：人工策展的行业、角色、能力、交付方式和客户类型标签。
- 双嘉宾节目作为一个访谈档案展示，同时在统计中按实际人数计数。
- 标签面向匹配与展示，不等同于资质认证或合作承诺。

## 6. 验收标准

- 58 期节目连续、无缺失，且每期具备封面、小宇宙链接与 Shownotes。
- 每期均有唯一详情页和完整分类。
- 搜索与四类筛选可组合使用，支持清空和无结果反馈。
- 封面在桌面端与移动端均可加载，页面无横向溢出。
- 中英文 URL、canonical 与 hreflang 正确。
- 联系电话可直接拨打，页面不出现公开报价。
- AI 和爬虫能访问目录页、详情页、站点地图、`llms.txt` 与 JSON 目录。

## 7. 后续建议

- 每次节目上线后运行 `npm run podcast:sync-guest-directory` 同步公开内容。
- 新嘉宾补充策展标签后再进入公开目录，避免完全自动分类造成错配。
- 后续可增加“生成甲方候选清单”和“按项目组合 2–4 位 FDE”的内部功能；仍不在公开站点展示价格。
